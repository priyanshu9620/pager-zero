- **D-19 · 2026-11-09 · Synthetic backend = one object implementing every Protocol.** Method names must therefore be unique across Protocols (`lag_history`, `cache_history`, `flag_history` — not three `history`s). Real backends will be separate classes; the bundle `Adapters` hides the difference.
- **D-20 · 2026-11-09 · The world heals on the correct fix.** `GroundTruth.matches()` decides; on match `now` advances 3 min and every `(series, baseline)` in `recovery_plan` tails back to baseline. This lets the agent's `verify` step be honest instead of being told "fixed". Wrong fixes are recorded but change nothing.
- **D-21 · 2026-11-09 · Scenario variants + red herrings are mandatory.** Every family has ≥2 evidence shapes or a decoy (unrelated deploy, old flag flip, harmless sibling commit) so the bench can't be passed by pattern-matching the family name.
- **D-22 · 2026-11-09 · Ruff: E501 ignored** (formatter owns code width; long log/cause strings are fine).
- **D-23 · 2026-11-09 · Mutating MCP tools are registered only when the server runs with `--actions`.** "Unreachable before approval" is enforced at the process level, not by prompt. The agent uses a read-only session for investigation and opens an actions session only in `execute` after the interrupt.
- **D-24 · 2026-11-09 · Synthetic world persists to a pickle state file (`--state`).** Needed because approval may resume in another process and the MCP server is spawned per session; all sessions for one incident share the file. Live backends don't need it.
- **D-25 · 2026-11-09 · Tool outputs are pre-digested for LLMs.** Series → {first, min, max, last, change_vs_start, first_deviation_at, 16-point trace}; logs → {total, top_messages w/ first_seen, sample}. Raw dumps would blow the context on every step and bury the signal.
- **D-26 · 2026-11-09 · Triage and verify are deterministic code, not LLM calls.** Triage = fetch incident_context + service_info; verify = re-query the alert's key metric and compare last vs baseline/peak (recovered if ≤1.5× baseline and <50% of peak; lag uses 2×). Saves tokens and makes verification unfakeable.
- **D-27 · 2026-11-09 · No plan when the diagnosis is `unknown` or confidence < 0.3.** The incident ends `unresolved` for a human; the agent never proposes a fix it can't justify.
- **D-28 · 2026-11-09 · Structured-output schemas avoid `dict` fields.** `FixPlan.args` is a list of {key, value:str} coerced via `ACTION_SIGNATURES`. Reason: open `additionalProperties` breaks some providers' schema validation.
- **D-29 · 2026-11-09 · Default free model = `gemini-3.5-flash-lite`.** Measured: 1.4 s/tool-call turn, correct on both live scenarios. Bench will also be run on a stronger model when available (Claude once credits exist, or `gemini-3.5-flash`).
- **D-30 · 2026-11-09 · Memory is hypotheses, not proof.** Recall results are injected as "similar past incidents (for hypotheses, not proof)"; the agent must still gather evidence. Remember only real diagnoses (family ≠ unknown), only after the incident finishes.
- **D-31 · 2026-11-09 · Bench runs with memory OFF by default.** Otherwise incident i's stored diagnosis would make incident i+6 (same family) easier and inflate the number. `--memory` exists to measure the lift separately.
- **D-32 · 2026-11-09 · Bench scoring is deterministic (no LLM judge).** Four booleans per incident: family, culprit named, fix matches, verified. Conservative on purpose; a judge would be a second model to argue about.
